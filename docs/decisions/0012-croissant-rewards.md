# 0012 — Croissant reward system for avoiding sweets
Date: 2026-10-04 · Status: accepted

**Decision:** Treat-free days earn rewards. Every N completed treat-free days (default 2, configurable 2–3) earns a "croissant pass", capped per week (default 3). A pass is spent from Home (Sweets card → "Use pass") and logs a croissant (flagged as reward: adds kcal/sugar to daily totals but doesn't count as a sweet or break a treat-free day). Progress is shown on Home and per person on Insights → Sweets (stamp squares, passes ready/used).
**Consequences:** Only completed days count (today is pending). Passes used are tracked per person; weekly reset and sharing/gifting passes between partners are not modelled yet.
