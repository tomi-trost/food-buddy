# 0004 — Bottom tabs + central snap FAB
Date: 2026-10-04 · Status: accepted

**Decision:** Tabs Home / Meals / Plan / Fridge, with a central camera FAB launching the Snap flow (modal). Insights and Settings reachable from the Home header (ring tap, 📊, avatar).
**Alternatives:** Insights as a fifth tab (crowds the bar).
**Consequences:** Snapping a meal is one tap from anywhere. Revisit if Insights is used often.
