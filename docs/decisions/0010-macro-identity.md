# 0010 — Macro identity (icon + colour per nutrient)
Date: 2026-10-04 · Status: accepted (colours open to tweak)

**Context:** There is no universal standard; apps loosely converge on protein = red/purple, carbs = amber/blue, fat = yellow/blue, fiber = green.
**Decision:** kcal = flame/burnt orange, protein = dumbbell/brick red, carbs = wheat/amber, fat = drop/muted violet (blue read as water), fiber = leaf/green, sugar = cube/berry pink. Muted tones to stay within the calm palette. Defined once in `MAC` in `index.html`; shown as tinted tiles and legend icons.
