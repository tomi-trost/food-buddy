# 0021 — Curated catalog of common foods from USDA and Ciqual (first step of M4)
Date: 2026-10-12 · Status: accepted

**Context:** Only the mock's 23 ingredients existed, so the first real meals came back half empty (zucchini, pesto: no nutrients). The full M4 import (USDA + Ciqual, ~10,000 rows) needs alias work first: raw names like "Squash, summer, zucchini, includes skin, raw" match the model's "zucchini" badly, and a wrong match is worse than none.
**Decision:** A hand-picked catalog of ~250 everyday foods, each pointing to one source row: **USDA SR Legacy** (public domain) for the basics, **ANSES Ciqual 2020** (Etalab open licence, attribution) for European/Italian foods USDA lacks or gets wrong for us (mascarpone, prosciutto crudo, grana, gnocchi, cooked polenta, egg pasta, plant drinks, cocoa as on EU labels). Each row has a clean name, emoji, category, shelf life and the aliases the model is likely to use. Picks in `api/scripts/{usda,ciqual}_catalog.txt`; `scripts/build_catalog.py` reads the official downloads and writes `api/app/nutrition/data/*_catalog.csv` (committed; credits in `data/SOURCES.md`). `python -m app.nutrition.seed` loads them on every API start. Rules: plate weights are as eaten, so grains, pasta, legumes and meat use cooked values; a name or alias belongs to exactly one row; no alias to a "close" food when the values differ a lot (burrata stays unmatched rather than counting as mozzarella). Tests check every row's energy against its macros.
**Learning what's missing:** every analysis counts the ingredient names that matched nothing (`unmatched_ingredient`); `python -m app.nutrition.unmatched` lists them, most frequent first, as the to-do list for the catalog.
**Alternatives:** Import all of SR Legacy + Ciqual now with generated aliases (fast, noisy matches); only one source (USDA misses Italian foods; Ciqual names are French-first).
**Consequences:** Rarer foods still come back unmatched; the user picks one by hand, and the name shows up in the unmatched list. Prices are unknown (0) for catalog rows. The full import and Open Food Facts lookup stay in M4 and can reuse the build script.
