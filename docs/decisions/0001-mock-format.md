# 0001 — Single-file HTML clickable mock
Date: 2026-10-04 · Status: accepted

**Context:** Need to iterate UX before choosing a framework.
**Decision:** One `index.html`, vanilla JS/CSS, hash routing, fake data, phone frame on desktop.
**Alternatives:** Multi-file static pages (harder to keep navigation fluid).
**Consequences:** Fast iteration, no build step; will be rewritten in the real stack later (web + native).
