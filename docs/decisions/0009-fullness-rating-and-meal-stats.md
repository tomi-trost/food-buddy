# 0009 — "How filling" feedback and meal stats
Date: 2026-10-04 · Status: accepted

**Decision:** Each rating includes a satiety answer (left us hungry / just right / too heavy). It does **not** affect the 1–5 score. The Nutrition tab shows a tip (e.g. add carbs/fiber when hungry). Each meal tracks `cooked` count and last-cooked date, shown on the meal and sortable in the feed.
**Consequences:** Satiety is per meal, not per portion size — later we may want it per portion/amount to tune quantities automatically.
