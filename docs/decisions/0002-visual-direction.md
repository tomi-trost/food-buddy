# 0002 — Warm & food-forward visual style
Date: 2026-10-04 · Status: accepted

**Context:** Photo-centric app used daily in the kitchen.
**Decision:** Warm neutrals, one accent (tomato), rounded cards, photo-led, light + dark themes.
**Alternatives:** Clean/minimal grey; playful bold.
**Consequences:** Palette lives in CSS tokens on `:root`; easy to retheme.
